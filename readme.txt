== Description ==

Nerds Toolkit provides reusable WordPress building blocks without imposing a client brand or requiring a specific theme.

Features include:

* Shared business contact settings.
* Reusable site layouts with safe public rendering.
* Accessible WordPress navigation and site identity components.
* Optional Elementor Free widgets.
* Optional WooCommerce catalogue and product enquiry tools.
* Local assets with no tracking, telemetry or remote fonts.

Stored settings and layouts are preserved when the plugin is deactivated.

== Installation ==

1. Upload the `nerds-toolkit` directory to `/wp-content/plugins/` or install the release ZIP.
2. Activate Nerds Toolkit from the Plugins screen.
3. Configure shared details under Nerds Lab in the WordPress administration area.
